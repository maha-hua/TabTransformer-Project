# TabTransformer Project

Deep learning project using TabTransformer for bank deposit prediction.

## Project Overview
This project applies the TabTransformer architecture on tabular banking data to predict whether a client will subscribe to a term deposit.

## Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- TabTransformer implementation using TensorFlow
- Hyperparameter tuning
- Model evaluation using:
  - Accuracy
  - ROC-AUC
  - Confusion Matrix
- Comparison with baseline models:
  - Logistic Regression
  - Decision Tree

## Technologies Used
- Python
- TensorFlow / Keras
- Scikit-learn
- Pandas
- Matplotlib
- Seaborn

## Results
The final TabTransformer model achieved better performance compared to traditional baseline models.
